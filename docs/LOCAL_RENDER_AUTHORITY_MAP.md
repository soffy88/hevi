## Pre-P7 modules outside this map

These render without being providers, which is R2 in the audit:

| module | renders via | in provider policy? |
|---|---|---|
| `hevi/renderers/remotion.py` | `npx remotion render` | **yes** (P9.1.c) |
| `hevi/renderers/html_gsap.py` | Playwright + ffmpeg | **yes** (P9.1.d) |
| `hevi/renderers/ffmpeg.py` | ffmpeg | **yes** (P9.1.d) |
| `hevi/assembly/remotion_render_workflow.py` | delegates to the renderer | indirectly |

All four renderers now have catalogue identities, and none may prove its own output:
`_hash_file` / `_probe_duration` are gone from `hevi/renderers/`, enforced by AST tests
over imports and call argv. **R2 is closed for identity and for artifact authority.**

`hevi/renderers/` remains the *execution* surface; `hevi/qualification/providers/` is the
*qualification* surface. A caller may still invoke a renderer directly — that API is
preserved deliberately — but a renderer can no longer assert that its own output is
valid.
