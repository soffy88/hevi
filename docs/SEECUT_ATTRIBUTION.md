# SEECUT_ATTRIBUTION

本项目 hevi/judge 参考 SeeCut (https://github.com/YeJe-cpu/SeeCut, PolyForm Noncommercial 1.0.0) 的方法论：
- 使用 Antigravity CLI (agy) 让 Gemini 直接观看 mp4；
- 硬伤检查 + 两两对比评委（交换位置各判一次，两次都赢才算赢）；
- 生成 v1 → 硬伤检查 → 改进项转参数 → 生成 v2 → 两两对比，赢了才采纳；最多 3 版。

未复制其任何代码、提示词原文、组件或字体，全部为 clean-room 重写。仅借方法。
