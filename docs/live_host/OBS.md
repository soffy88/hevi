# 赛博小雅直播：弹幕 + OBS

1. 启动：`scripts/live_xiaoya.sh <抖音直播间号>`（停止：`systemctl --user stop hevi-live-xiaoya`）
2. OBS：来源 → 媒体源 → 取消“本地文件” → 输入 `rtmp://192.168.0.168:1935/xiaoya`（同局域网）或 `rtmp://100.86.95.70:1935/xiaoya`（Tailscale）；也可用 `rtsp://<ip>:8554/xiaoya`。勾选“网络缓冲 1 MB”可减少卡顿。
3. 画布 1080×1920 竖屏；画面右上角固定「AI生成」。
4. 手动弹幕/测试：`curl -X POST -d '{"user":"测试","text":"小雅你好"}' http://127.0.0.1:8765/`
5. 中继 mediamtx（unit `hevi-live-relay`）只允许本机推流，外部只能拉流。

实测（2026-10-12，CPU）：抖音真实直播间 120 s 收到 670 条弹幕；从弹幕到小雅开口 6–15 s；推流 20 fps，120 s 墙钟 119.95 s，晚帧 21/2400；RTMP 与 RTSP 两路拉流各 40 s 正常（1080×1920 h264 + aac）。
已知：同时只答一条，热门直播间多数弹幕会被跳过（优先带问号/“小雅”的）；3B 模型回答质量一般。
