# HEVI 3O runtime map

InkOS is not linked into HEVI. The reverse-spec maps capabilities to existing
HEVI responsibilities:

- canonical objects and authority: `hevi.obase.creative`
- deterministic state, persistence, memory, locks, and export primitives:
  `hevi.creative.oprim`
- professional policy and safety registry: `hevi.creative.oskill`
- composed creative production modules: `hevi.creative.omodul`
- externally callable service names: `hevi.creative.oservi`

The public direction remains `User -> HEVI service -> Production Graph ->
artifact/evidence/verdict`. Internal 3O names are not a user-facing product
contract.
