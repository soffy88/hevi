# HEVI MCP 能力清单

> 由 `scripts/export_api_inventory.py` 从 MCP 注册表自动生成；不要手工编辑。

| 工具 | 说明 |
|---|---|
| `hevi.chat` | Xia 会话制片助理:状态/推进/审计/修复/提升 |
| `hevi.create_three_view` | 生成角色三视图提示词(正/侧/背) |
| `hevi.edit_video_elements` | 编辑视频元素列表(插入/替换/删除) |
| `hevi.execute_canvas` | AI执行画布工作流，运行有向图节点管线并返回每节点结果 |
| `hevi.gen_multi_angle` | 生成主体多角度提示词 |
| `hevi.gen_storyboard` | 生成分镜网格提示词 |
| `hevi.generate_longvideo` | 创建可查询、可下载的长视频生产任务 |
| `hevi.get_produce_job` | 查询 Veya/制片厂成品工单 |
| `hevi.list_capabilities` | 发现 hevi 可用的 AI 创意辅助能力清单 |
| `hevi.list_studio_lines` | 列出可交接成品的产线与运行时 |
| `hevi.make_transition` | 首尾帧过渡视频生成 |
| `hevi.media_resolve` | 媒体台账:一个 resolve 动词(bgm/sfx/image/voice/grade/lut…)→ 冻结文件 |
| `hevi.predict_story` | 基于参考图像预测剧情走向 |
| `hevi.produce_finished` | Veya 调 Hevi 成品:选产线填槽,返回工单/成片路径 |
| `hevi.promote_candidate` | 候选提升双轨:探索候选 → 主线资产(评分过线+无冲突) |
| `hevi.repair_plan` | 失败镜头 → 修复计划(agent 表映射 + 尝试预算 + 收敛决策) |
| `hevi.run_character_consistency` | 角色一致性工作流：多场景保持人物一致 |
| `hevi.run_comic_to_animation` | 漫画转动画工作流 |
| `hevi.run_storyboard_workflow` | 多镜头分镜工作流：脚本到分镜网格 |
| `hevi.subject_create` | AI管理主体库：创建角色/人物/产品/场景主体 |
| `hevi.subject_search` | AI管理主体库：按类型/关键词搜索主体 |
| `hevi.tick_daily` | 解说/历史现场日更排产一拍(可带发布交接单) |
| `hevi.watch_video` | 看视频:URL/本地 → 帧+转写+联络表(摄入侧,参考 /watch) |
