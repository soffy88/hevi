## 3D models in `source/` and `cache/`

All GLB models under `assets/scene3d/` come from the release packages of
**花叔《3D Vibe Coding 手册》v260914c** ("3D Vibe Coding Handbook"), used as
read-only reference material:

- Upstream repository: https://github.com/alchaincyf/3d-vibe-coding-handbook
- Release: `v260914c` — https://github.com/alchaincyf/3d-vibe-coding-handbook/releases/tag/v260914c
- Licence: **CC BY-NC-SA 4.0** — https://creativecommons.org/licenses/by-nc-sa/4.0/
  (attribution, non-commercial, share-alike)
- Author: 花叔 (AI Native Coder)
- The models were generated by the author with his own Tripo credits; the
  per-asset specification table is the handbook's Appendix A.

The handbook's own download mirror is kept outside the repository at
`/data/soffy/refs/3d-vibe-assets/` (the 11 release packages, ~80 MB, SHA-256
verified against the GitHub Releases API). Only the small GLBs actually used by
the SCENE3D templates are committed here; each is well under 5 MB.

## Design references (not committed as models)

- `07-designs-prompts-park-prince` — the Little Prince planet input images and
  prompts. Used only as *composition and palette reference* for the
  `little_planet` template. The SCENE3D template is built from procedural
  geometry; no upstream demo code or web page is copied.
  **Note**: the handbook deliberately does not ship Little Prince character
  models (active trademark / image rights); we ship none either.
- `11-scripts` — the handbook's tool scripts (`E1-减面极限.py`,
  `E2-批量流水线.py`, `glb_downscale.py`, `measure_glb.py`, …). Read for method
  only; `assets_pipeline` is an independent implementation.

## Vendored code

- **Three.js r169** — MIT, already vendored at
  `hevi/layer4_legacy/scene3d/vendor/three/`. The r169 addons
  (`GLTFLoader.js`, `SkeletonUtils.js`, `BufferGeometryUtils.js`) added for the
  VIBE3D-R1 character work are from the same `three@0.169.0` npm package
  (`npm pack three@0.169.0`), so all five files come from one version — mixing
  versions of the addons fails with a module-resolution error that looks exactly
  like a missing file (§12).

No paid API (Tripo, GPT, …) is called anywhere in this pipeline.
