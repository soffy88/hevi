# Stocksera vs Helios — source viability and reuse assessment

Assessment date: 2026-10-22 UTC
Stocksera source: https://github.com/guanquann/Stocksera
Inspected ref: e5908bc960c2726d5419b426ef641e57665124ac (2024-08-19); public GitHub API reported MIT, 785 stars, 127 forks, 6 open issues, pushed_at 2024-08-19, archived=false.
Live-probe evidence: evidence/provider_probes.txt

## Decision

**Do not transplant Stocksera code into Helios in this round.** The highest-potential concepts are relevant, but the current-source probes do not establish stable access to its Reddit and keyword-specific Google Trends inputs; Helios already has sentiment/trend scoring, a crypto news pipeline, CoinGecko integration, and a funding-rate API path. The remaining feature set is predominantly equity-specific. The expected value of copying its Django/MySQL collectors into Helios is therefore lower than the integration and maintenance cost. This conclusion is about code reuse now, not a claim that social data has no predictive value.

## Architecture and licensing

Stocksera is a legacy Django/MySQL application with scheduled jobs and UI views; its README asks operators to configure multiple external API keys. Its license is MIT with the copyright notice “Copyright (c) 2021-2024 Stocksera by guanquann”. If any code is reused in a later approved change, preserve that notice and add a record to Helios THIRD_PARTY_NOTICES.md. No Stocksera source file was copied into Helios during this review, so no Helios source or notice file was modified.

The Helios 3O spec places project HTTP routes in the project service layer, outside the reusable core libraries. No new 3O package is warranted for a provider probe. Any future adapter should fit Helios's existing provider/collector boundary and flow through the existing API, fusion and evidence contracts. Helios must remain advisory-only and must not gain order-placement/execution behavior.

## Real-request evidence summary

See evidence/provider_probes.txt for actual status/response excerpts. Verified live success: Alternative.me Fear & Greed, OKX BTC/ETH perpetual funding, CoinGecko BTC/ETH spot prices, and Google Trends broad RSS. Verified current failure / inadequate result: unauthenticated Reddit JSON (403 HTML), Google Trends keyword explore (429 HTML), GDELT BTC search (timeout), and Binance funding (451 location restriction). These observations are specific to the probe runtime/time, not a universal guarantee of provider status.

## Recommendation

Stop after evaluation. Reconsider only a credentialed, permitted Reddit adapter if it can supply stable, incremental BTC/ETH discussion metadata beyond Helios's existing sentiment inputs. For trend and derivatives data, integrate only after checking whether the existing Helios trend/funding pipelines need a genuinely distinct provider. No 3O worktrees, code changes, commits, pushes, service restarts or production-container operations were undertaken in this no-transplant branch.
