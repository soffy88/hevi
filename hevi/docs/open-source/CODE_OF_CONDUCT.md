# 行为准则 (Code of Conduct)

## 我们的承诺

作为 Hevi 项目的参与者和贡献者，我们承诺为每个人创造一个友好的、包容的环境，无论其经验水平、性别、性别认同和表达、性取向、残疾、个人形象、身体大小、种族、年龄、宗教或国籍如何。

## 我们的准则

### 积极的行为

我们希望看到以下积极行为：

* **友善和包容** - 使用欢迎和包容的语言
* **尊重** - 尊重不同的观点和经验
* **建设性反馈** - 提供友善的建设性批评
* **接受反馈** - 优雅地接受建设性批评
* **关注目标** - 专注于项目的目标和社区的利益
* **同理心** - 向社区其他成员展示同理心

### 不可接受的行为

以下行为不可接受：

* **使用性化语言或图像**，以及不受欢迎的性关注或进步
* **侮辱/贬低评论**，人身攻击或政治攻击
* **公开或私下的骚扰**
* **未经明确许可，发布他人的私人信息**，如物理或电子地址
* **其他可能被视为不专业的行为**

## 我们的责任

项目维护者有责任澄清可接受行为的标准，并应在必要时采取适当的、公正的纠正措施。

项目维护者有权删除、编辑或拒绝不符合本行为准则的评论、提交、代码、维基编辑、问题和其他贡献，也可临时或永久禁止任何他们认为不合适、威胁、冒犯或有害的行为者。

## 范围

当个人代表项目或其社区时，本行为准则适用于项目空间和公共空间。代表项目的方式包括使用官方项目电子邮件地址、通过官方社交媒体帐户发布，或担任指定代表的角色。

## 执行

辱骂、骚扰或其他不可接受的行为可以向项目团队报告，邮箱：[project-email@example.com]。所有投诉都将得到及时和公平的审查。

项目团队有义务对事件报告者保密。具体执法政策的详细信息可能会单独发布。

项目维护者如果违反行为准则，将由项目领导层其他成员处理。
