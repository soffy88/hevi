# Beginner science-film SOP: method attribution

The working method in `pipeline.beginner_science_workflow`
(seven-column script table, pause-marked narration segments,
sample-first gate, A/B roll discipline, template registry,
music on section changes) was rewritten clean-room from the
ideas in a forwarded essay about a beginner producing a short
science explainer with AI in one to two hours. No wording,
prompt text, table text, or example script from the essay was
copied; all docstrings, field names, and test fixtures in this
repository are self-authored.

Named templates are recorded with honest connection status:
`lemo-opuscar` (lemomo-ai/lemo-opuscar, MIT) and `handraw-style`
(yang0/handraw-style) are backed by capabilities already in
this repository; `eian-riso-broll`, `mg-styles-15`,
`vox-director`, and `sweety-handdraw-video` are selection
references only and are not connected here. Recording a style
analysis never copies another creator's text, prompts, or
material.

Services named in the essay that are not connected here:
MiniMax voice (no key), green-screen image generation, and
video-model generation. They are recorded as pending in code
and documentation, never claimed as connected.
