# /pixel-diary

像素角色加对话框类视频的复刻方法，迁自 Easel 的 skill-pixel-diary-method
（视频处理归 hevi，Easel 只负责与各平台对接；Easel 侧该技能已收窄为
平台对接说明，不再保留视频处理方法细节）。

> 边界（先读）：本技能只提供方法与质检清单，不含出片引擎、
> 不含像素精灵工具、不跑样片、不渲染、不下载字体。
> 引擎与精灵工具如需落地，是另一次任务，需 Soffy 另行拍板。
> 本技能不发布；分集过稿后是否交渲染，另走 hevi 的提案/确认门，
> 本技能不替渲染线做决定。

方法来源：garycaogan/pixel-diary（MIT 协议）。本技能是 hevi 自写的
方法文档，不复制该仓库的代码，不搬原片台词，不使用 Claude /
DeepSeek 同人形象。角色与人设必须原创。

## 输入

- 对标视频链接或本地视频文件（一条已公开的像素角色加对话框类视频）
- 对标数据：播放、评论、作者、发布时间（由 Easel 侧发现与平台对接
  给出，或人工提供；本技能不重新抓取，本技能不做平台采集）
- 原创设定：自有角色名、人设、赛道、语言（中/英文），不得使用
  他人同人形象与原片角色名
- 真实记录（若分集涉及真实过程）：审片记录、系统记下的数字、
  会议原话等原始材料，不得事后补写

## 输出

- 逐镜头分镜表：时间码、画面、台词原文（仅用于拆解对照，不进入成片）、
  音效、该镜的作用
- 节拍映射表：事件链照原片，台词按每镜作用重写，不搬原句
- 角色方案：草稿来源、像素化要求、表情清单（眨眼、说话、开心、冒汗等）
- 分集文件草案：一集一个文件，字段见 references/method.md，
  骨架示例见 references/episode-example.json（文案全为占位）
- 质检报告：只挑毛病，按 references/pitfalls.md 逐条打勾或打回，
  打回必须写清哪一条、哪一句、证据是什么

## 执行步骤

### 1. 拆对标（输入，不重做采集）

- 输入：对标视频 + 已给出的播放、热评、同类号数据。
- 输出：逐镜头分镜表。能看视频也能听声音的模型只负责出表，
  不负责写成片台词。
- 不做：不直接把原片台词、原片角色、原片画面搬进成片；
  无配音的片不做这一步的语音识别，见 pitfalls.md 第 1 条。

### 2. 节拍映射（核心）

- 输入：分镜表。
- 做法：事件链照原片，一镜一作用；台词照每一镜的作用重写，
  人设、梗、结尾求关注方式全部换成自己的。
- 输出：节拍映射表，每行写明原镜作用、重写后的台词要点、
  该镜要弹出的卡片或道具。
- 不做：不改事件链去凑时长，不为押韵改事实，不编造真实过程。

### 3. 做角色（方案层，不出精灵文件）

- 输入：原创人设 + 图像模型画的草稿（草稿来源必须写清）。
- 做法：草稿压成像素后，照坐标逐格画出表情差分：眨眼、说话、
  开心、冒汗等；说话帧与表情帧分开标。
- 输出：角色方案 + 表情清单 + 道具清单，道具必须在像素尺寸下
  一眼认得出，认不出就重画，不重新生成。
- 不做：不输出精灵图片文件，不承诺走动、复杂动作、配音；
  本技能不含精灵工具，工具落地另行拍板。

### 4. 写分集（核心）

- 输入：节拍映射表 + 角色方案 + 真实记录。
- 做法：一集一个文件，写清台词、谁在说、什么表情、说到哪个词
  弹出哪张卡片；账本只用系统记下的真实数字，过程只用审片记录
  里的原话与结果。
- 输出：分集文件草案，字段与骨架见 references/method.md
  与 references/episode-example.json。
- 不做：不写引擎渲染参数，不写竖屏版式（当前方法只覆盖横屏
  思路，竖屏需另行定版式），不编剧情、不编数字。

### 5. 出片质检（只挑毛病，不出片）

- 输入：分集文件草案 + 对标分镜表 + 真实记录。
- 做法：把草案与原片节拍逐项对齐，只列问题：节拍是否一一对应、
  台词是否搬了原句、道具是否认得出、账本数字是否被盖章压住、
  停留是否按字数算、声音设定是否降调压音量。
- 输出：质检报告，逐条引用 references/pitfalls.md 的规则编号，
  通过 / 打回二选一，不写「差不多」。
- 不做：不渲染、不录制、不调 HyperFrames，本技能没有出片步骤；
  质检通过不等于可以渲染或发布，渲染与发布另走确认门。

## 与相邻 hevi 技能的边界

- story-to-film：hevi 的「一句话出成片」全链编排（HyperFrames 成片
  或 PixStag 镜头包）；本技能不是全链编排，只做像素日记这一种
  形式的复刻方法，不替 story-to-film 的输入格式做转换。
- hevi-hyperframes：hevi 的第二渲染运行时；本技能不调用它，
  未来引擎对接时，分集文件到渲染线输入的转换另行定。
- hevi-story：手绘日记漫画技能（分句成 beat、三态揭示或卷页翻书）；
  本技能是像素角色加对话框形式，两者形式不同，不混用。
- final_qc：成片质检技能；本技能的质检是分集草案阶段的只挑毛病，
  不替代成片质检。
