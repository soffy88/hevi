# 双镜头文字分镜

**用途**：把一句话创意压成两支镜头（总长 8–12 秒）的文字分镜，供后续生成或拍摄。
只输出文字，不建节点、不调用任何生成工具，除非用户明确要求。

## 何时用

- 用户要“先看看两镜怎么拆”，不想马上花钱生成。
- 短视频开头需要“一个动作 + 一个转折”，两镜比多镜更好控节奏。

## 步骤

1. **写一句可拍的核心动作**：谁、在哪、做什么、结果如何。不要形容词堆叠。
2. **分两镜**：镜头一负责“建立”（环境/人物/动作起势），镜头二负责“变化”
   （结果、反应或反转）。两镜必须是同一时空，别写成两个故事。
3. **每镜只写四项**：时长、画面、声音、待确认。画面写“看得见的东西”，
   声音写“听得见的东西”（对白/环境/音乐），不要写“氛围感”这种不可执行的词。
4. **待确认项不超过 5 条**：画幅、人物年龄/性别、道具、是否需要旁白、交付平台。
5. 用户确认后再进入节点或生成；未确认前不扩展成 6 镜、不自动加旁白。

## 输出格式

```
总时长：8 秒 ｜ 画幅：16:9（待确认）

镜头一（4 秒）
画面：深夜书桌，台灯下的人把冷掉的咖啡推到一边，伸手去够另一只杯子。
声音：空调低鸣；杯子碰到桌面的轻响。
待确认：咖啡杯品牌？人物是否需要露正脸？

镜头二（4 秒）
画面：同一位置，窗外转亮，人抬头，手里换成冒热气的杯子。
声音：鸟叫进入；音乐起。
待确认：是否需要字幕写“第二天”？
```

## 常见错误

- 两镜之间换场景/换人 → 观众读成两支片子。
- 用“镜头缓缓推近”代替“画面里发生了什么” → 生成模型无法执行。
- 把 5 条以上待确认项塞给用户 → 决策疲劳，先问最影响画面的两条。
