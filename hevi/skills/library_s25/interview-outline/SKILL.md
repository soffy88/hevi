# 采访提纲

**用途**：为一个具体人物/事件准备可执行的三问采访提纲，含条件追问、补拍清单与授权记录。
只输出文字；不代替受访者回答，不编造引语。

## 步骤

1. **先写采访目的（一句话）**：这条采访要回答观众的哪一个问题。
   目的不写清，问题就会变成“聊聊你的感受”。
2. **三个开放问题**：按“发生了什么 → 为什么 → 代价/改变”排序。
   每个问题必须能引出 30 秒以上的回答，不用“是不是/对不对”开头。
3. **每个问题配 1 条条件追问**：只有当对方回答里出现某个具体词时才追问
   （例：如果提到“亏钱”，追问“第一次发现亏钱是哪一天？”）。
4. **补拍清单**：手、工作台、走路、门牌/招牌，各 1 条，写清拍什么、为什么。
5. **授权记录**：姓名、用途、平台、期限、是否可剪辑/二创，逐项留空待签。
   没签字之前，素材只能内部预览，不能发布。

## 输出格式

```
采访目的：________

Q1（发生了什么）：________
  追问（若提到 ____）：________

Q2（为什么）：________
  追问（若提到 ____）：________

Q3（代价 / 改变）：________
  追问（若提到 ____）：________

补拍：1) ____ 2) ____ 3) ____
授权：姓名 ____ ｜ 用途 ____ ｜ 平台 ____ ｜ 期限 ____ ｜ 可剪辑 是/否
```

## 边界

- 不设计诱导性问题（“你是不是也觉得他们很过分？”）。
- 不承诺播出时间、不代替法务判断；未成年人、医疗、纠纷类采访必须转人工。
