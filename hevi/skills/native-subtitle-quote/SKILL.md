# /native-subtitle-quote

把一段本地视频做成一张 3:4 字幕长图。画面全部来自视频本身
的真实帧，拼图由 hevi 能力 `image.native_subtitle_stitch`
完成（实现见 hevi/capabilities/native_subtitle_stitch.py）。
本技能不下载、不转写、不识别文字、不联网、不发布。

方法思路借鉴 chengyi-ai/native-subtitle-quote-image（MIT，
Copyright 2026 程意，v2.10.3）。本技能的文字与代码均为
hevi 重新撰写，没有复制该仓库的代码、提示词、数据表或
原文句子，也没有获得原作者的背书。详见
references/method.md。

> 边界（先读）：只有本地视频文件。没有在线视频获取、没有
> 浏览器 Cookie 读取、没有版本检查。权利依据没有声明就
> 不开工；模式没有选定就不渲染；说话人没有分清就不拼图。

## 开始时先确认三件事

1. **模式。** 用一句话问用户，二选一，不替用户选：
   原生字幕保留画面里已有的字幕，不重绘文字；脚本字幕
   把用户确认过的台词后期画到真实帧上，并标明是后期
   字幕。用户没选时只做只读检查，不渲染；选定的模式
   与素材不匹配时说明原因、征求改选，不自行切换。
2. **权利。** 要求用户声明视频来源与处理、发布的依据
   （自己拍摄、已获授权、公开许可或其他可核查的依据）。
   只说“网上找的”“大概能用”不算声明，不开工。
3. **说话人与台词。** 一张图只放一个说话人，除非用户
   声明是一问一答（恰好两句、两人、来源中相邻）。台词
   必须是已核对的文字，不得编造人名、数字、引语或翻译。

## 输入

- 本地视频文件路径（一条视频）；时长、语言、目标图片数
- 模式：native 或 script，二选一
- 权利声明：来源 + 依据 + 是否公开发布
- 时间点：每张图 2 到 7 个，严格递增、小于视频时长
- 脚本模式：与时间点一一对应的已审核台词（每句带说话人）
- 可选：字幕带位置、主图占比、是否允许低于 720p、是否覆盖

## 执行步骤

1. 读 references/method.md，确认本单的模式、带位置与
   布局规则。先用能力探查视频尺寸与时长；低于 720p
   时先征得用户确认再继续，不得默认放行。
2. 逐个时间点回看完整画面（用抽帧预览）：确认主体是
   说这句话的人、构图完整、没有闭眼或动作模糊、没有
   转场黑帧与播放器界面。字幕带预览只看带的位置，不
   读字幕文字来改写它。
3. 原生模式：确认每个时间点的字幕带里确实有烧录字幕；
   相邻两帧看起来几乎一样时停下，说明是静止画面，不
   为出图而放行。脚本模式：逐句核对台词与时间点、说话
   人，问答结构确认两句在来源中相邻。
4. 调用能力渲染，写出 JPG、manifest JSON 与总览图。
   不覆盖已有成品，除非用户明确说了覆盖。
5. 打开成品逐张看：主图构图、字幕完整、条带紧凑、
   脚本模式的“脚本字幕”标签在位、水印未被遮盖。低清
   晰度上采样要在交付时写明不是真实清晰度。交付时列
   出模式、时间点、说话人、权利依据与仍有限制。

## 输出

- 一张或多张 3:4 JPG（脚本模式固定 1440x1920；原生
  模式按源画面等比缩放，高度随内容走）
- manifest JSON：模式、时间点、字幕带、说话人、权利
  依据、警告
- 总览图：全部成品的缩略网格
- 交付说明：模式、说话人、权利依据、构图或清晰度限制

## 不要做的事

- 不下载在线视频，不读浏览器 Cookie，不做版本检查
- 不 OCR、不重绘、不翻译、不改写原生字幕
- 不把两个说话人的句子拼成一个人的观点
- 不遮盖、模糊、涂抹水印与台标
- 不在没有权利声明时开工，不在没有确认时用低清源
- 不发布；配文与平台发布走 Easel 侧入口
