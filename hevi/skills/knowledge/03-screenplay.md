# 剧本阶段手艺手册

这一层的唯一使命:把"文字"变成"能拍的动作"。
数字人只能照剧本演。剧本里只给"谁说了什么",产出必然是一排大头念台词;剧本里给了
"勒马 → 下马 → 扑通跪地 → 肩膀剧烈起伏",才有场面、有情绪、有节奏。

## 一、核心转换:小说语言 → 剧本语言

小说用一句"张飞报信"交代一个事件;剧本要用**四场**把它排成戏。

一条可执行的换算:**一句叙述 → 1 个动作节拍 → 1 场戏 → 2–4 个镜头**。
把"一句顶一场"的段落找出来,逐个拆开。

## 二、六条硬规则

1. **每场必须有可拍的物理动作。** 走、跑、坐、开门、端杯、转身、下马、跪、扶、骑马——写不出动作,这场就是废的。
2. **一场一拍点。** 一个情绪或动作节拍单独成场,不要把三轮对白挤进一个大头场。宁可多场。
3. **narration 写画面,不写概要。** 写"谁在哪、朝向谁、做什么、什么表情、环境什么样";不写"众人商议""交代军情"。
4. **对白带情绪与身体状态。** 台词或叙述里点出"哭腔""低到几乎听不见""顿足怒吼"。
5. **对白带受话人(target)。** A 对 B 说,受话人就是 B;独白/对众留空。
6. **第 1 场冷开场必须有运动主体**(跑、走、推门、纵马),禁止静物特写开场。

## 三、可拍性边界:哪些动作能写,哪些写了必崩

**能写(常见、单主体、粗动作)**:

- 位移类:跑、走、转身、坐下、起身、下马、跪下
- 取放类:端杯、放下、拿起、推门、关门
- 大幅身体动作:拥抱、扶起、跌倒、拔剑、捶桌
- 群体类:众人起身、散去、围拢

**不能写(精巧物理交互 / 微动作)**:

- 两物精确对撞:两杯沿严丝合缝碰上
- 精确插接:螺丝拧进孔、钥匙插进锁孔
- 微小肌肉:睫毛颤、指节掐白、眼球转动
- 复杂多手协同:一边抱着孩子一边系鞋带

规则:凡是需要**两件物体同时精确接触**或**亚毫米级动作**的场景,一律改写成"分开的两拍"
("伸手" → "接过"),或者换成同框但不接触的表现。

## 四、字数与时长的换算(直接决定后续剪辑)

- 中文口播 **4–5 字/秒**;情绪台词放慢到 **3–4 字/秒**。
- 一句台词 20 字 ≈ 4–5 秒,已经很接近单镜上限。
- 一场戏的台词总量控制在 **8–14 句**,折合 **30–50 秒**,对应 **4–8 个镜头**。
- 全片台词总量按提案的配音字数走,偏差超过 ±10% 就回上游改。

自检:把某一场的台词逐句念一遍,若累计超过 45 秒,这至少是两场。

## 五、场次结构模板

冷开场用**建场**收:第一个镜头交代环境与人物在干什么;第二个落点才给静态细节或第一个特写。

推荐配比(每场内部):

- 建场/动作镜头 ≥ 2 个
- 对白镜头 2–4 个
- 纯静态细节镜头 ≤ 1 个

整场戏里**没有任何身体动作**的段落,一律删除或改写。

## 六、复杂度与 CG 量标记

逐场标 `production_complexity` 与 `cg_level`(low / medium / high):

- 单人室内对话 → low
- 双人互动 + 真实环境 → medium
- 大场面、群像、特殊物理 → high

约束与提案层一致:**连续两场 high 必须合并或降级**;全片 high 场次占比不超过 15%。
标记的作用是排产,不是装饰——标了 low 的镜头,后期不许偷偷升难度。

## 七、语言处理:白话但不稀释

- 文言字词转现代口语:不要"之乎者也/尔汝/寡人"的文言腔,也不要半文半白。
- **保留名句、比喻、意象**:"得何足喜,失何足忧"说成人话,但"得失"这个意象本身不能丢。
- **保留语气分量**:该恳切就恳切,该痛切就痛切,不因为白话而变得温吞。
- 原文说三层意思,白话也说三层。宁可长而忠实,不要短而失神。

## 八、人物状态管理

- 区分**人物恒定设定**(长相、体貌、身份)与**当前状态**(浴血、破损、湿透、醉态)。
- 当前状态写进本场叙述,但**不得当成人物固有属性**带到后续所有场次,除非剧本显式说明。
- 同一场里,角色的服装、持物、伤势必须前后一致;不一致要在剧本里显式写一次变更(换装/包扎/丢失)。

## 九、常见失败模式

- **纯大头对白场**:整场没有一句身体动作,渲染出来就是一张嘴。
- **概要当画面**:"众人商议军情"——镜头无从下手,只能生成一群人站着。
- **名句被冲淡**:为了白话把原文的锋利比喻改成了平铺直叙。
- **人物状态污染**:第 3 场带伤,到第 20 场还没好,后面全带伤。
- **精巧物理交互**:写了"茶杯在他手里转了半圈",生成必崩。
- **冷开场静物**:第一个镜头是"旧皮箱特写一闪",观众不知道这是什么片子。

## 检查清单

- [ ] 每一场都有至少一个可拍的身体动作
- [ ] 一场只有一个情绪/动作节拍,无三轮以上对白挤场
- [ ] narration 全部改写成了"谁在哪/朝向谁/做什么/什么表情/环境"
- [ ] 每句对白都有情绪、身体状态与受话人
- [ ] 无精巧物理交互与亚毫米级动作
- [ ] 第 1 场冷开场有运动主体,不是静物特写
- [ ] 逐场标了复杂度与 CG 量,high 场次占比 ≤15%
- [ ] 白话化但名句/意象/语气分量都保住了
- [ ] 台词总量与提案配音字数偏差 ≤10%
- [ ] 人物当前状态与固有设定分开,且变更已显式写明
