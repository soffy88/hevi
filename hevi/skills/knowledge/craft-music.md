# 音乐手艺手册

音乐在片子里干三件事:**推进情绪、划分结构、驱动节奏**。三件里任何一件没做,
音乐就只是背景装饰,不如不加。

## 一、选曲三要素

按这个顺序筛,一步都别跳:

1. **速度(BPM)**:必须与剪辑节奏匹配。见下表。
2. **调性**:大调偏明亮开阔,小调偏内敛沉重;带五声的偏东方/民谣感。
3. **织体**:单乐器(独奏/弦乐)偏私密克制;加打击乐/合成器 pad 偏宏大推进。
   纯钢琴适合访谈与思考段落,不适合动作段落。

**速度与镜长换算**:

| BPM | 每拍时长 | 与剪辑的配合 |
| --- | --- | --- |
| 60 | 1.0 秒 | 极慢,适合 4–8 秒长镜 |
| 90 | 0.67 秒 | 中速,适合 2.5–4 秒镜 |
| 120 | 0.5 秒 | 快,适合 1.5–2.5 秒快切 |
| 140+ | 0.43 秒 | 极快,预告/追逐段落 |

选择 90 BPM 配 1.5 秒的快切,或选 120 BPM 配 6 秒长镜,都会别扭。
**先定剪辑平均镜长,再选 BPM**,不要反过来。

## 二、结构:音乐有段落,片子才有段落

- 8 小节 4/4 拍 **120 BPM** 约 **16 秒**;90 BPM 约 **21 秒**。
- 把剧本段落映射到音乐段落的自然句读:开场段 → 主歌 → 副歌 → 尾声。
- **结构必须对齐**:情节高潮应对上音乐的高点或节奏变化,而不是随机对上。
- 音乐结构比画面结构**晚半拍进入**更自然,直接对齐会显得机械。

## 三、入点与出点

- **入点**:音乐比画面提前 **0.5–1.0 秒**进入(J-cut),观众会觉得"事情要开始了",而不是"配乐开始了"。
- **出点**:音乐比画面延后 **1–2 秒**退出(L-cut),给画面一个收尾的空间。
- **转场处**:优先用音乐跨越切点,不要在音乐重拍上切画面(会像被绊了一下)。
- **卡点**:关键动作的剪辑点与音乐重音重合,力量最大;一场戏卡 2–3 次就够,全片卡点会变成 MV。

## 四、情绪曲线

- 音乐强度曲线必须与情节强度曲线**同向**。
- 情绪反着走是最常见的灾难:危险场面配欢快音乐,悲剧场面配宏大弦乐,观众会出戏。
- 全片音乐强度峰值 **不超过 2 次**;片长 30 秒内的高点 **不超过 1 次**。
- 峰值之后要有**明确的回落**,否则观众会疲劳,结尾也失去对比。

## 五、音量平衡(混音硬指标)

- **人声**峰值 -6 ~ 0 dBFS,平均响度是整片基准。
- **BGM 比人声低 12–18 dB**。听不清台词就是配乐失败,不管音乐多好。
- **侧链 ducking**:人声进入时 BGM 自动降 6–12 dB,释放时间 200–400 ms。
- **整片响度**约 **-14 LUFS ±1 LU**,**真峰值 ≤ -1 dBTP**(与审片标准一致)。
- 人声段落之间响度不能忽大忽小,段落间差异 ≤3 LU。

## 六、环境声与音乐的关系

- 音乐**不要盖住环境声的关键信息**:脚步声、门响、雨声起始——这些是叙事信息。
- 户外场景可把音乐压低 2–3 dB 留出环境空间感。
- 室内独白段落,完全静场 + 极低音乐,往往比满配乐更高级。
- 结尾音乐戛然而止是最低级的处理。收尾建议:音乐渐出 **2–4 秒**,或留 **0.5–1 秒**的纯环境声收场。

## 七、版权

- 确认授权范围:**平台内使用 / 可商用 / 可否二次分发 / 有效期**。
- 免费曲库的"可个人使用"通常**不覆盖商业发布**,必须逐首确认。
- 自制音乐要在台账里写清来源(素材包、生成、委托)。
- 授权不明的音乐,一律不进时间线。

## 八、常见失败模式

- **音乐盖住台词**:观众听不清内容,直接划走。
- **情绪反着走**:该紧张时安静,该欢快时悲伤。
- **速度与剪辑打架**:2 秒一镜配 60 BPM,画面像掉帧。
- **全程满配乐**:观众失去喘息,30 秒就开始屏蔽听觉。
- **结尾戛然而止**:没有收尾动作,像被人掐断。
- **音乐结构与画面结构错位**:换段落在剧情中点,情绪被拦腰截断。
- **响度忽大忽小**:段落切换处观众要重新调音量。

## 检查清单

- [ ] 先定剪辑平均镜长,再选 BPM,两者匹配
- [ ] 音乐段落的自然句读已与剧本段落对齐
- [ ] 入点提前 0.5–1.0 秒,出点延后 1–2 秒
- [ ] 音乐强度曲线与情节强度同向,全片峰值 ≤2 次
- [ ] BGM 比人声低 12–18 dB,侧链 ducking 已配
- [ ] 整片响度约 -14 LUFS ±1 LU,真峰值 ≤ -1 dBTP
- [ ] 段落间响度差 ≤3 LU
- [ ] 卡点一场 ≤3 次,未通篇卡点
- [ ] 结尾有 2–4 秒渐出或纯环境声收场
- [ ] 授权范围逐首确认,不明音乐未进时间线
