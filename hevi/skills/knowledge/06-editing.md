# 剪辑阶段手艺手册

剪辑是**节奏工程**,不是拼贴。判断一次剪辑好不好,只有一个办法:关掉声音看一遍,
再看一遍只听声音。两条都顺,才算过。

## 一、三段式,不要跳

1. **粗剪(Assembly)**:只做取舍与顺序,不上色、不加转场、不做字幕。目标是 85–90% 时长。
2. **精剪(Fine Cut)**:定切点、定节奏、定转场,补空镜,做声音先行。目标 100% 时长。
3. **锁画(Lock)**:输出画面锁定文件给调色/字幕/发布。此后任何画面改动都要走变更记录。

粗剪没看完就调色,是这条流水线最贵的浪费。

## 二、切点:切在动作的前后,不要切在动作的最剧烈处

- **动作中切**:一个动作跨两个镜头,在动作**进行到 1/3 前**切出、或在动作**完成后 1/3** 切进。
  切在动作最剧烈的那一帧,观众会看到"跳",这是新手最常见的错误。
- **眼神切**:A 看向画外 → 切到 B,接住视线。切早了在等,切晚了散神。
- **出画/入画切**:人物走出画再切入新构图,天然顺。
- 同一条动作的切点,两镜的**运动方向必须一致**(都在往右走,不能一镜往右一镜往左)。

## 三、镜头时长与节奏阶梯

| 节奏 | 平均镜长 | 适用 |
| --- | --- | --- |
| 快(预告/信息密集) | 1.5–2.5 秒 | 清单罗列、数据 |
| 中(常规叙事) | 2.5–4 秒 | 主力段落 |
| 慢(情绪/建立) | 4–8 秒 | 建立镜、情绪转折 |

规则:

- **不要连续三个镜头等长**。等长三连 = 节拍器,观众会开始数拍子。
- 节奏阶梯要有起伏:长 → 短 → 中 → 短 → 长,是正常曲线;连续六个同档就是催眠。
- **快切段落后必须给一个长镜头**收,给观众喘息。
- 镜头数校验:镜头数 ≈ 时长 ÷ 平均镜长,偏差 20% 以内算正常。

## 四、声音先行与滞后(廉价的高级感)

- **J-cut**:下一镜声音提前 **0.3–0.6 秒**进来,画面后到。用在转场、悬念、场景切换。
- **L-cut**:上一镜声音延后 **0.5–1.5 秒**退出,画面先走。用在情绪余韵、人物离场。
- 每场用 1–2 次就够。全片到处用,观众会觉得"一直在响"。
- 关掉画面只听声音,转场是否仍然成立?不成立就是画面在替声音干活。

## 五、转场

- **硬切优先**。90% 以上的转场应该是硬切,这是免费的、也是最不抢戏的。
- **叠化**:时长 **0.5–1.0 秒**,只用于"时间流逝/时间跳跃"。用错地方会显得业余。
- **划像/翻页**:现代题材尽量不用,会暴露年代感。
- **闪白/闪黑**:用于强冲击瞬间,时长 **1–3 帧**。一镜全片最多用一次。
- **遮罩转场**(同形状匹配):同一物体前后形状一致时可用,成本高,慎用。
- 场景切换处优先用**声音先行**而不是画面特效。

## 六、空镜与环境镜

- 全片空镜占比 **10–20%**。没有空镜的片子会喘不上气。
- 空镜要承担功能:交代地点 / 过渡时间 / 情绪留白 / 给字幕一个不抢戏的背景。
- 空镜不要静,要有轻微运动(风吹、行人、光变),**静止空镜超过 3 秒就是废片**。

## 七、字幕与画面

- 字幕入点尽量与语音起点对齐,误差控制在 **±200 ms**。
- 说话时画面不要同时出现大面积文字,除非是刻意的引用卡。
- 关键信息的字幕用**单行 12–16 字**,分两行也可,但不要一行超过 20 字。

## 八、常见失败模式

- **没有建立镜头**:开场直接进对白,观众不知道在哪。
- **所有镜头等长**:节拍器式剪辑。
- **跳轴**:剪辑时没检查空间关系,人物忽然换边。
- **音频断裂**:每次切画面都切声音,对话被切得支离破碎。
- **转场滥用**:每一场都用不同特效,像 PPT。
- **尾段拖沓**:最后 20% 时长信息密度断崖式下跌,该砍的没砍。
- **结尾无落点**:音乐一停画面就断,没有收尾动作。

## 检查清单

- [ ] 走过粗剪 → 精剪 → 锁画三段,没跳步
- [ ] 切点避开了动作最剧烈帧,动作跨镜运动方向一致
- [ ] 无连续三个等长镜头,长镜与快切有起伏
- [ ] 镜头数与时长换算偏差 ≤20%
- [ ] 每场有 1–2 处声音先行/滞后,关画面只听声也能走通
- [ ] 转场以硬切为主,叠化仅用于时间跳跃,闪白全片 ≤1 次
- [ ] 空镜占比 10–20%,且都有轻微运动
- [ ] 字幕入点与语音误差 ≤200 ms
- [ ] 逐场检查轴线与视线,无跳轴
- [ ] 结尾有收尾动作,不是音乐戛然而止
