# 分镜阶段手艺手册

分镜是把"场"拆成"镜"。拆得好不好,看两件事:**观众每一刻知道该看哪儿**,以及
**每个镜头自己站不站得住**。镜头拍不拍得动是素材层的事,不该在这里浪费。

## 一、三类镜头,场内部必须穿插

| 类型 | 作用 | dialogue_lines |
| --- | --- | --- |
| 建场镜头 | 交代环境与人物在干什么 | 空 |
| 动作镜头 | 推进剧情的可拍动作 | 空 |
| 对白镜头 | 人物开口说话 | 填台词 + 说话人 |

规则:

- 开场至少一个建场/动作镜头,且**必须有运动主体**(跑、走、推门、纵马),禁止静物特写开场。
- 关键情节(刺杀、擒拿、搜身、递交)必须用**动作镜头演出来**,不能只靠台词交代。
- 非对白镜头的画面描述写**动作**,绝不能写"旁白:xxx"。
- 一场 4–8 镜。

## 二、时长与打包

- 每镜 **2–5 秒**。低于 2 秒,观众来不及看清;高于 5 秒,不剪辑就闷。
- 同场连续镜头打包进一次生成 **不得超过 15 秒**。
- 镜头数校验:镜头数 ≈ 场时长 ÷ 平均镜长。差 20% 以上说明切得不匀。
- 关键动作镜允许**加长到 6–8 秒**(一镜到底的完整动作),但全场最多一处。

## 三、景别与运镜

景别速查(按裁切):

- 远景:环境占主导,人物小于画面 1/8,交代地点与规模。
- 全景:人物全身,看清姿态与走位。
- 中景:膝/腰以上,对话主力景别。
- 近景:胸以上,情绪主力景别。
- 特写:脸/手/物,强调与转折。

运镜词表(用这一套,不要自由发挥):固定 / 跟拍 / 左摇 / 右摇 / 推进 / 拉远 / 环绕 / 升降 / 手持。

规则:

- 同一场里,**相邻两镜的景别差至少一级**(中景 → 近景可以,中景 → 中景 不行)。
- 连续 3 镜同景别 = 幻灯片感,必须换。
- 运镜要服务于动作:人物在动 → 跟拍/手持;静态强调 → 固定;情绪推进 → 推进;规模揭示 → 拉远。
- 一场戏内同一种运镜最多连用 2 镜。

## 四、轴线与空间连续(最容易崩的地方)

- **180 度规则**:对话双方 A/B 相对而站,A 恒在画左、B 恒在画右。越轴会让观众瞬间失去空间感。
- 越轴只有两种合法做法:①拍一个**过轴镜**(人或物从两人之间穿过);②插入一个**中性正面镜**(正对轴线)。
- 角度差遵守 **30 度规则**:连续两镜的机位夹角小于 30 度,等于跳帧,改角度或换景别。
- 视线匹配:A 看 B → A 的近景看向画右;B 看 A → B 的近景看向画左。
- 道具位置、人物服装、手持物,跨镜必须一致;不一致就在前一镜里显式交代(他拿起杯子 → 下一镜杯子在手)。

## 五、注意力脚本:每一拍观众该看谁

每一拍标一个焦点主体与理由:说话 / 反应 / 即将说话 / 揭示 / 入画 / 关键动作。

- 说话者拍 2–3 拍后,**必须给受话者一个反应镜**(哪怕只有 1.5 秒)。
- 揭示性信息(信被打开、门后有人)先给**局部**,再给**全貌**。
- 入画的人物要有**入画过程**,不要让他凭空出现在画面中央。

## 六、画面描述书写口径

按固定顺序组织,降镜头间漂移:

**①景别/机位/运镜 → ②场景环境 → ③主体人物或关键对象 → ④动作与状态 → ⑤氛围情绪 → ⑥必要风格收束**

规则:

- 优先写**主角色**、优先建立**主场景**;道具只在进入主动作或构图焦点时才重点写。
- 不要每样都平均铺陈成流水账,一个镜头最多 **2 个被强调对象**。
- 只写画面里有的东西,不写旁白文字、不写声音、不写"镜头切换到"。
- 已锁定的人物名/场景名**原样引用**,禁止改写、翻译、换同义词、加前后缀。

## 七、动作弧(action_beats)

有明显肢体动作的镜头,把动作拆成 **触发 → 峰值 → 收束** 三拍:

- 首拍是动作**刚触发**的瞬间;
- 中拍是力量/情绪的**峰值**;
- 末拍是**收束/结果**态。

例:"张飞拔剑自刎" → ["猛地抽剑架上脖颈", "剑刃压出白痕", "宝剑坠地,刘备紧抱住他"]。

- 纯静态场景镜、纯对白镜没有动作弧时,数组留空。
- 每个动作拍点一句,写具体画面动作,不写内心活动。

## 八、声音先行/滞后

- **J-cut**:下一镜的声音提前 **0.3–0.6 秒**进入,画面后切。做转场与悬念。
- **L-cut**:上一镜的声音延续 **0.5–1.5 秒**到下一镜画面。做情绪余韵。
- 对白镜头之间不必每次都用,每场用 1–2 次就够,全用会腻。

## 九、常见失败模式

- **大头对白流水账**:8 个镜头全是近景说话,像口播视频。
- **景别不跳**:连续中景,视觉上没有剪辑感。
- **越轴**:A 突然从画左跳到画右,观众以为换人了。
- **静物开场**:第一个镜头没有运动主体。
- **动作弧缺失**:写"他很愤怒",但画面上什么都没有。
- **名称漂移**:同一个人在不同镜头里被写成三个名字。

## 检查清单

- [ ] 开场有建场/动作镜头,且带运动主体
- [ ] 关键情节有动作镜头演绎,不是只靠台词
- [ ] 每镜 2–5 秒,同场连续打包 ≤15 秒
- [ ] 相邻镜景别差 ≥1 级,无连续 3 镜同景别
- [ ] 同一种运镜未连用超过 2 镜
- [ ] 无越轴;如越轴,已安排过轴镜或中性镜
- [ ] 相邻机位夹角 ≥30 度,视线方向匹配
- [ ] 每拍有明确焦点主体;说话者每 2–3 拍有受话者反应镜
- [ ] 画面描述按六段口径组织,每镜强调对象 ≤2 个
- [ ] 动作镜头有触发/峰值/收束三拍
- [ ] 已锁定的人名/场景名原样引用,无改写
