# 提案阶段手艺手册

提案是**决策文件**,不是文案。看完提案,制片人必须能直接回答:投不投、投多少、什么时候开机。
读不出这三个答案的提案,写得再好也是废纸。

## 一、先写一句 logline,写不出来就别往下做

格式:**谁 + 想要什么 + 阻碍是什么 + 代价是什么**。

- 反例:"一部关于盐税兴衰的历史解说片。" —— 没有主角、没有冲突、没有代价。
- 正例:"一个靠盐引吃饭的账房,想保住自家那块盐池,却要在盐税翻三倍和全家流放之间选。"

自检:把 logline 给一个不了解本项目的人看,他能不能复述一遍?不能就是太长或太虚。

## 二、提案必须写死的七项(缺一项都算未完成)

1. **时长**:精确到秒(如 92 秒),不要写"3 分钟左右"。
2. **画幅与分辨率**:竖屏 1080×1920 / 横屏 1920×1080 / 方形 1080×1080,并说明发布平台。
3. **帧率**:25 或 30,全片唯一,中途不得混。
4. **风格锚点**:**恰好 3 个**可验证的描述 + **2–3 部参考片**。多了等于没有,少了无法验收。
5. **核心信息点数量**:3–5 个,逐条列出。
6. **场景与镜头规模**:场景数、镜头数、镜头平均时长。
7. **风险与预案**:每条风险写"触发条件 + 退路"。

## 三、规模换算(不要拍脑袋估)

- 平均镜长 **2–5 秒**(快节奏 1.5–3 秒,慢 3–5 秒)。
- **镜头数 ≈ 成片时长 ÷ 平均镜长**。92 秒、平均 3.2 秒 → 约 29 镜。
- **配音字数 ≈ 成片时长 × 4.5 字/秒**(中文常规语速)。92 秒 → 约 410 字。
- 配音占比:讲解型 60–75%,剧情型 25–40%。占比高于 75% 时必须补画面动作。

四项写进提案,后面每一层都得对得上;任何一层超标,回到提案改,不要在下游偷偷加。

## 四、复杂度分级与配额

| 级别 | 判据 | 单镜典型成本 |
| --- | --- | --- |
| low | 单主体、室内或简单外景、无特效 | 最低 |
| medium | 双人互动、真实场景、复杂光线 | 中 |
| high | 大场面、群像、特殊物理、CG 特效 | 最高 |

- **一场戏最多 1 个 high 镜头。** 连续两场各挂一个 high,风险叠加,直接砍。
- 全片 high 镜头占比不超过 **15%**。
- 提案里要显式写出:哪些镜头是 high,为什么非它不可。

## 五、风格要可验收,不要写形容词

"高级感""电影感""史诗感"——这三个词在验收时无法判定,等于没写。

改成可验收描述:

- 光线:侧逆光为主,高对比,阴影保留细节不压死。
- 色彩:低饱和青灰,肤色单独保留暖调。
- 节奏:平均镜长 3 秒,动作点用短切(≤1.5 秒)强调。
- 质感:手持轻微晃动(幅度 < 画面高度 2%),无稳定器漂浮感。

每条风格描述都要能被"合格/不合格"二选一地判。

## 六、提案版本

- **60 秒口头版**:一句话 logline + 三个画面示意 + 一句差异点,给决策人听。
- **书面完整版**:上面七项全写齐,附参考片、风险表、排期与预算量级。

两个版本的核心数字必须一致。不一致说明没想清楚。

## 七、需求冻结

提案通过后:

- 把通过的版本号与日期写进文档头部,后续任何变更都要写**变更记录**(日期 / 提出人 / 改了什么 / 影响哪几层)。
- 变更累计影响镜头数 ±10% 或成片时长 ±10% 时,**必须回到提案层重新确认**,不能由某一层自行吸收。
- 口头改主意不算变更,必须落到变更记录。

## 八、常见失败模式

- **概念堆砌**:提案里塞了三个主题,谁都没讲透。
- **风格不可验收**:全篇形容词,后期无从对齐。
- **规模含糊**:只写"若干镜头",不做时长/镜头数/字数换算。
- **复杂度失控**:每场都想上大场面,预算和时间双爆。
- **没有退路**:风险只有描述,没有触发条件和替代方案。

## 检查清单

- [ ] logline 四要素齐全,且外人能复述
- [ ] 时长精确到秒,画幅/分辨率/帧率写死
- [ ] 风格锚点恰好 3 个且可验收,参考片 2–3 部
- [ ] 核心信息点 3–5 条,逐条列出
- [ ] 场景数 / 镜头数 / 平均镜长 / 配音字数四者换算自洽
- [ ] high 镜头清单列出,单场 ≤1 个,全片占比 ≤15%
- [ ] 每条风险写了触发条件与退路
- [ ] 60 秒版与书面版数字一致
- [ ] 变更记录机制已写明
