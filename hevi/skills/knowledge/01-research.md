# 研究阶段手艺手册

研究不是"把搜到的都记下来"。研究的唯一交付物是**一批能被拍出来的结论**。
如果一句话结论没法转成一个画面或一句话解说,它就不是研究素材,是背景噪音。

## 一、先定研究的问题,再开始搜

动手前先回答三件事,写进 brief 顶部:

1. **这件片子给谁看?** 受众决定深度。给行业内部看,要多给数字与机制;给大众看,给反直觉与后果。
2. **观众看完多知道一件事?** 写不出这一句,说明选题没立住,先换题。
3. **为什么是现在?** 近 3 个月发生了什么变化,让旧内容失效?答不上来,就是常青内容,不值得立项。

## 二、证据分层,每条结论都必须标层

| 层级 | 含义 | 可用方式 |
| --- | --- | --- |
| A 一手 | 原始文件、判决书、财报、当事人采访实录、官方统计 | 可以直接当作事实陈述 |
| B 二手 | 权威媒体、学术论文、行业报告 | 可以陈述,须注明出处 |
| C 传闻 | 论坛、匿名爆料、单一自媒体 | 只能作为"说法",必须标注为待证 |

规则:

- **任何一个出现在成片里的具体数字,必须有 A 或 B 层证据。**
- 传闻进片时,必须出现"有说法认为""据未经证实的报道"这类限定语,不能改写成陈述句。
- 关键结论至少要有**两个独立来源**,否则降级为 C 层处理。

## 三、事实核验清单(逐条过,不要凭印象)

- **数字**:量级对不对?是"增长 3 倍"还是"增长 3 个百分点"?注意同比/环比、绝对值/占比。
- **时间**:事件发生在哪一年?资料发布日 ≠ 事件发生日,片子里要说事件日。
- **人名**:姓名写法、职务、生卒年。三个以上中文人名放一段口播里,观众记不住。
- **地名**:行政区划改动、译名统一(同一个地方全片只用一个名字)。
- **因果**:资料说"因为 A 所以 B",有没有可能只是同期发生?能查到的因果要标注推断。
- **过时**:超过 6 个月的行业数据、超过 1 年的政策条款,一律复核一次。

## 四、把结论翻译成"可拍的画面"

每条核心结论后面必须挂一个画面方案,三选一:

- **实拍/库素材能拍**:写清主体、动作、景别、环境。
- **只能生成**:写清能生成的抽象画面(数据可视化、示意图、氛围空镜)。
- **拍不了也没有**:接受纯口播 + 字幕图表,不要为了"有画面"生成假现场。

**红线:凡涉及真实人物、真实灾害、真实案情的画面,不得用生成内容伪装成现场记录。**
生成画面必须以"示意图/还原图"形式呈现,并在画面上打角标。

## 五、信息密度预算

- 每 **15 秒**至少要落进一个新信息点;连续 30 秒没有新信息,观众会走。
- 一条 60 秒的短片,承载 **3–5 个**核心信息点,超过 6 个必然记不住。
- 每个信息点配一个"锚":一个人名、一个数字、一个反常识的事实,三者至少占一个,否则观众记不住。

## 六、选题打分(立项前自评,每项 0–5)

| 维度 | 问题 |
| --- | --- |
| 信息增量 | 这个内容网上已经有了吗?已有的话,我们的差异是什么? |
| 可视化 | 核心结论能不能配出画面?不能,降级。 |
| 受众动机 | 观众看完能带走什么、能转述什么? |
| 证据强度 | 关键数字能不能找到 A/B 层来源? |
| 合规风险 | 有没有肖像、名誉、版权、行业监管风险? |
| 时效性 | 三个月后还成立吗?会过时的选题慎做。 |

总分低于 18 不立项。

## 七、交付格式

产出 research brief,固定五段:

1. **一句话结论**(不超过 30 字)
2. **核心事实表**(事实 / 证据层级 / 来源 / 出处时间)
3. **画面清单**(每条结论对应的画面方案,标明实拍/生成/无)
4. **风险清单**(合规、事实、时效,每条写处置方式)
5. **待补清单**(还缺什么、谁能补、什么时候补)

## 八、常见失败模式

- **资料堆砌**:brief 有 30 页,能进片的只有 3 句。
- **无出处数字**:片子里出现"高达 78%",找不到来源,后期被迫删。
- **结论不可视化**:整片全是口播 + 静态图,留存极差。
- **时效性失控**:做了三天,开拍前一周热点已经换人换事。
- **顺手扩题**:研究过程中发现更有趣的题目,结果原题没做完。

## 检查清单

- [ ] 开头写清了"给谁看 / 多知道一件事 / 为什么是现在"
- [ ] 每个进片的数字都有 A 或 B 层证据,或已降级为"说法"
- [ ] 每条核心结论后面挂了画面方案,并标注实拍/生成/无
- [ ] 人名、地名、数字、时间四类逐条核过一遍
- [ ] 信息点数量与成片时长匹配(15 秒 1 点,60 秒 3–5 点)
- [ ] 选题自评总分 ≥ 18,风险清单每条都有处置方式
- [ ] brief 五段齐全,待补清单有人有期限
