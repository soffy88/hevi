# 合成阶段手艺手册

合成是**骗眼睛**的活:让两个不同时空、不同介质的元素,看起来在同一时刻同一空间被同一台
摄影机拍到。合成失败几乎从不是技术问题,而是**光照、透视、运动、颗粒**四件事对不上。

## 一、先分层,再动手

标准分层顺序(自下而上):

1. **底板**:远景、环境、建筑、天空
2. **中景主体**:人物、主要动作物体
3. **前景**:遮挡物(栏杆、树叶、门框)、虚化元素
4. **氛围层**:雾气、体积光、烟尘、光晕
5. **调色层**:整体色彩统一
6. **字幕层**:最后加,不参与任何合成运算

规则:**先对齐,再合成,再调色**。顺序颠倒(先调色再对齐)会让匹配失效。

## 二、透视与尺度(最容易露馅的一类)

- 主体在画面中的**灭点**必须与底板一致。俯视/仰视错一个,观众说不出哪里怪,但就是不信。
- **焦距感一致**:底板是广角(强透视、大变形),主体就不能带长焦压缩。
- 尺度比例:人物在画面里占多高,直接决定远近感。对照建筑门窗、人、车做基准,不能凭感觉。
- 接触阴影必须存在。悬空的物体一律穿帮;把主体压进地面/桌面,加接触暗部。

## 三、光照(第一大穿帮来源)

必须对齐的四项:

- **光源方向**:底板主光从左来,主体高光也必须从左来。
- **光源色温**:黄昏暖光时,主体高光要带暖色;阴天冷光时,主体不能出现橙调高光。
- **光比**:底板是高反差逆光,主体不能是均匀柔光棚拍感。
- **环境色反弹**:主体暗部要吃到环境色(绿植的绿、砖墙的褐),纯黑暗部会显得像贴纸。

自查法:把主体单独看、放进底板看,两个观感的差异如果超过"一个滤镜",就是没对齐。

## 四、运动一致

- **相机运动方向与幅度匹配**:底板往左推,主体也要有同向同幅的位移。
- **速度曲线匹配**:匀速底板配缓入缓出主体,一眼假。快推时要同步轻微运动模糊。
- **遮挡关系**:前景遮挡物必须在主体**之上**;主体经过前景时要有正确的遮挡切换。
- 逐帧检查运动模糊方向:与运动方向垂直的模糊是错的。

## 五、抠像与边缘

- **边缘羽化 1–2 像素**。0 像素硬边是"贴纸感"的主因。
- 头发、半透明衣物、玻璃、快速运动边缘需要单独处理(分通道抠像 + 手动修补)。
- **去色溢出(spill)**:主体边缘残留底板颜色的绿边/蓝边,必须抑制。绿幕前拍的人物,发丝边几乎必有残留。
- 半透明物体(玻璃、纱、烟)不要抠,分层混合更省事也更真。

## 六、颗粒与噪点

- **颗粒是穿帮之王**。底板有胶片颗粒、主体没有,画面会明显"分层"。
- 做法:主体统一加一层与底板**同强度同尺寸**的颗粒,再做轻微模糊让颗粒尺度一致。
- 噪点(高 ISO 的彩色噪点)也要匹配,尤其暗部。
- 画面越干净,越需要手动加颗粒来"统一"。

## 七、色彩与输出

- 全流程 **Rec.709**;输出 sRGB。不要中途换色彩空间。
- 位深:中间链路 **16-bit**,输出 8-bit。多次叠加后 8-bit 极易出现色带。
- 合成完成后统一做一次全片色彩匹配:同场景不同镜头的白平衡、曝光、肤色必须一致,偏差 ≤3 IRE。

## 八、合成里的字幕与图形

- 字幕最后加,加在安全区内,不参与任何合成运算。
- 图形/图表类元素要有**投影或边框**,贴在画面上会像 PPT。
- 生成式字幕类工具出现错字、闪烁、字形变形,一律不采用,宁可不用。

## 九、常见失败模式

- **光源方向不一致**:底板逆光,主体正面平光,一眼假。
- **悬空**:主体没有接触阴影,飘在场景里。
- **颗粒分层**:合成边缘出现明显的"拼贴缝"。
- **缩放抖动**:逐帧尺寸有微小跳动,肉眼在运动中能察觉,静帧看不出来。
- **色边**:边缘一圈绿光/蓝光,夜景尤其明显。
- **景深不匹配**:底板前景虚化、主体全清晰,合成痕迹最明显的地方就是这里。
- **先调色后合成**:颜色已定,合成进来的新素材无法匹配。

## 检查清单

- [ ] 按底板→主体→前景→氛围→调色→字幕分层,顺序未颠倒
- [ ] 透视、灭点、焦距感、尺度比例与底板一致
- [ ] 主体有接触阴影,无悬空
- [ ] 光源方向、色温、光比、暗部环境色四项对齐
- [ ] 边缘羽化 1–2 px,无硬边;发丝/半透明已单独处理
- [ ] 去色溢出已完成,无绿边/蓝边
- [ ] 颗粒强度与尺寸与底板一致,无拼贴缝
- [ ] 相机运动方向与速度曲线匹配,运动模糊方向正确
- [ ] 前景遮挡关系正确,主体经过时有遮挡切换
- [ ] 全流程 Rec.709,中间链路 16-bit
- [ ] 同场景跨镜色彩已统一,亮度肤色偏差 ≤3 IRE
- [ ] 逐帧看过运动,无缩放抖动
