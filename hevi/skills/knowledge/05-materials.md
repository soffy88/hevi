# 素材阶段手艺手册

素材阶段的交付不是"一堆文件",而是**一张能直接进剪辑的素材台账**。
没有台账的素材,等于没有素材——后期找不到、不知道能不能用、不知道授权到哪天。

## 一、素材类型与各自边界

| 类型 | 适用 | 注意 |
| --- | --- | --- |
| 实拍 | 人物动作、真实环境、需要表演的内容 | 排期最长,最先锁定 |
| 生成 | 氛围空镜、示意画面、非真实人物的动作补充 | 不能伪装成真实现场 |
| 库素材 | 空镜、城市、风景、器物 | 必须逐条看授权与水印 |
| 档案/新闻 | 历史影像、新闻画面 | 授权范围最窄,先确认再下载 |
| 屏幕录制/图表 | 数据、界面、流程 | 录制分辨率 ≥ 目标分辨率,避免放大发虚 |
| 3D 渲染 | 确定性镜头、需要精确控制的画面 | 渲染时长是隐藏工期,要留余量 |

**红线:真实人物、真实灾害、真实案情的画面,不能用生成内容冒充现场记录。**
生成画面必须带"示意图/还原图"角标。

## 二、技术规格:先定死,再采

- **画幅**:竖屏 1080×1920 / 横屏 1920×1080 / 方形 1080×1080。全片唯一,中途不得改。
- **帧率**:25 或 30,全片唯一。素材与时间线帧率不一致会重采样,画质必然掉。
- **色彩**:Rec.709,sRGB 交付。全流程锁死,不要中途引入其他色彩空间。
- **位深**:交付 8-bit;如果中间要大量合成与二级调色,内部链路走 16-bit 更稳。
- **音频采样率**:48 kHz,声道 2(立体声)或按最终版要求。
- **目标分辨率下**:单条素材分辨率 **不得低于**目标分辨率的 1.0 倍;低于 1.5 倍明显发虚,宁可不用。

## 三、安全区(竖屏尤其致命)

竖屏平台上下都有 UI,必须预留:

- **顶部**:距顶 ≥ 12%(约 230 px @1080p),留给账号信息与进度条。
- **底部**:距底 ≥ 15%(约 290 px @1080p),留给标题、话题与交互按钮。
- **左右**:距边 ≥ 5%(约 54 px),关键人物与文字不要贴边。
- **字幕**:放在底部安全区**上方**,底边距底 ≥ 18%,最多占两行。
- 横屏同样留 10% 标题安全区,但空间宽松得多。

## 四、检索词写法(决定你能不能找到东西)

库素材检索词按五要素拼:**主体 + 动作 + 景别 + 镜头运动 + 光线**。

例:`老人 手持 编织 近景 缓慢推进 逆光` 优于 `老人`。

- 中英文各试一遍,英文库通常更全。
- 用同义词扩展:"编织/针织/手工",搜 3 组再判断。
- 光线词一定要写:dawn / golden hour / overcast / night / neon。光线是风格的一半。

## 五、生成素材的操作要点

- **一次出 4 个候选再择优**,不要一条不过就改提示词重发。生成有随机性,择优比重抽快。
- 候选评分维度:构图(主体位置与留白)、景别是否对上、光线是否对上、动作是否成立、风格是否与同组一致。
- **同系列一致性**:固定同一段风格描述、同一参考图或种子,风格词一字不改。风格词每镜微调,是画面漂移的头号原因。
- 生成的静物/空镜优先用,人物复杂动作次之,多人交互最后。

## 六、台账(必做)

每条素材一行,字段:

`id | 文件路径 | 类型 | 来源/授权 | 采集或生成参数 | 画幅/分辨率/帧率 | 时长 | 可用于哪些镜头 | 状态 | 备注`

- **状态**四档:可用 / 待修 / 弃用 / 待确认授权。
- 授权要写清**来源平台 + 授权类型 + 是否可商用 + 有效期**。
- "待确认授权"的一律不进剪辑时间线。

## 七、给剪辑留余量

- 每个镜头前后各多留 **2 秒把手**(handles),剪辑点才有得挪。
- 关键镜头留**完整动作**而不是掐好的片段;掐片段的活儿留给剪辑。
- 空镜与环境镜备量 **≥ 镜头数的 20%**,剪辑时大概率要用。
- 同一构图多备 2–3 条不同运镜的,给剪辑做 A/B 切换。

## 八、评审与淘汰

素材定稿前过一遍,标状态:

- **可用**:直接进时间线。
- **待修**:可修项明确(亮度不足、构图偏、可裁切修),修完再评。
- **弃用**:构图不可救、与风格冲突、授权不明。不要舍不得,素材冗余比素材不足危害小得多。

淘汰标准要硬:主体被边缘切掉、逆光过曝到面部无细节、画面有第三方水印或路人清晰可辨脸部——以上任一,直接弃用。

## 九、常见失败模式

- **规格不统一**:横竖混、帧率混,后期重采样全片发软。
- **无台账**:后期找不到某条素材,或误用了授权不明的。
- **竖屏顶格**:人物头顶被平台 UI 盖住。
- **生成素材风格漂**:每镜风格词都改一点,拼起来不像一部片子。
- **素材不足**:没有留把手、没有空镜,剪辑被时长绑架。
- **低分辨率硬上**:320×180 的素材放到 1080p 母版,放大后像马赛克。

## 检查清单

- [ ] 画幅/分辨率/帧率/色彩空间/采样率全片写死且一致
- [ ] 竖屏安全区:top ≥12%、bottom ≥15%、左右 ≥5%,逐条核过
- [ ] 台账字段齐全,每条素材有状态与授权信息
- [ ] "待确认授权"的素材未进时间线
- [ ] 每条素材分辨率 ≥ 目标分辨率,低质素材已淘汰
- [ ] 生成素材按同系列固定风格词,每镜 ≥4 个候选已择优
- [ ] 每镜前后留 ≥2 秒把手,空镜备量 ≥20%
- [ ] 主体被切边 / 过曝 / 有水印或可辨路人脸的素材已弃用
