# 配音表演手艺手册

配音的问题从来不是"声音好不好听",而是**有没有人在说话**。
平铺直读的配音,音色再漂亮,观众也会在十秒内关掉——因为没有人在思考、在犹豫、在坚持。

## 一、语速与时长(直接决定剪辑)

- 中文播讲 **4–5 字/秒**;情绪台词放慢到 **3–4 字/秒**;激烈台词 **5–6 字/秒**。
- 反推:一句 20 字台词,常规语速 **4–5 秒**。这已经是单镜上限,写稿时就要有数。
- 停顿也算时长。停顿不足会让观众来不及处理信息,句尾被下一句压掉。

**停顿标尺**:

| 停顿位置 | 时长 |
| --- | --- |
| 逗号 / 顿号 | 0.3–0.5 秒 |
| 句号 / 分号 | 0.6–1.0 秒 |
| 段落之间 | 1.0–1.5 秒 |
| 情绪转折(刻意留白) | 1.5–2.5 秒 |

## 二、重音:每句只重 1–2 个词

- 中文句子重读**不超过 2 个词**。全句都重读等于没有重读。
- 重音优先落在:**数字**、**人名**、**转折词**(但/却/才/原来)、**结论词**。
- 反例:"去年我们生产了三千吨合格产品。" → 重音在"三千吨"和"合格"。
- 用**加强力度 + 轻微延长 + 音高略升**三者叠加,单靠音量会被听成喊叫。

## 三、语调与句尾

- **陈述句**:句尾音高下降 **2–3 个音阶**,给"落定"感。
- **疑问句**:句尾上扬,但不要变成夸张的疑问语调。
- **感叹句**:重音 + 延长,句尾**不下落**(或只落 1 个音阶),否则听着像陈述。
- **反问句**:反问用陈述语调,不用疑问语调。
- 语气词(啊/呢/吧/吗)会影响语调走向,口播稿里能省则省。

## 四、情绪阶梯

- 一条 30 秒音频内,情绪变化**不超过 2 档**(如 平静 → 激动)。
  情绪像电车一样来回跳,观众会累。
- 建立一个**情绪基线**:每个角色有自己的常态语气,波动是围绕基线的,不是从零开始。
- 强度高的一次之后要有回落,不能连续两句都是最高强度。
- 情绪靠**速度、音高、力度、停顿**四个维度组合,不要只靠音量。

## 五、技术规格

- **录音电平**:峰值 **-6 ~ -3 dBFS**,不要贴着 0 dBFS 录。
- **底噪**:安静环境 ≤ **-60 dBFS**;有底噪必须降噪后再用。
- **格式**:48 kHz、24-bit 录制,交付 48 kHz。
- **句首留白 100–200 ms**,句尾留白 **200–400 ms**,给剪辑留改的余地。
- 每条音频单独成文件,文件名带角色名与句号,便于对齐。

## 六、读音表(配音前必须固化的清单)

建一张表,写死三列:**词 / 读音 / 例句**,覆盖:

- **多音字**:重、差、和、长、少、得、着、便、兴、藏、朝
- **人名地名**:全片统一读法,尤其生僻字与方言读法
- **专业术语**:化学式、机构名、外文人名、品牌名
- **数字与单位**:读法(15% 读"百分之十五"还是"百分之十五点")、百分号、货币
- **中英混排**:英文读音规则统一,不要一段一种读法

表定稿后**全片不得变更**。同一个人被读成两种音,观众会以为换了人。

## 七、同一角色的声线一致性

一个角色跨集/跨镜必须保持:

- 音色(同一音色库或同一克隆)
- 基线语速(±10% 内)
- 情绪基线(常态语气)
- 口音与方言

同一角色在不同场景里"像换了个人",是配音最严重的失误,比音色差异更难被接受。

## 八、常见失败模式

- **念稿腔**:全程一个语调、一个速度,像在读说明书。
- **情绪平**:没有转折,没有轻重,观众听十分钟就关掉。
- **数字念错**:百分比、年份、单位读错,是硬伤。
- **响度忽大忽小**:不同句子录的音量不同,剪在一起很明显。
- **停顿不足**:句尾被下一句吃掉,观众来不及反应。
- **多音字随意**:同一词在不同句读不同音。
- **角色漂移**:同一人音色/语速/情绪基线不统一。
- **过度表演**:情绪比画面高半档,人物显得浮夸失真。

## 检查清单

- [ ] 语速符合 4–5 字/秒,情绪段 3–4 字/秒
- [ ] 停顿按标尺设置,句首留 100–200 ms、句尾留 200–400 ms
- [ ] 每句重音 ≤2 个词,落在数字/人名/转折/结论
- [ ] 句尾语调符合句型(陈述下落、疑问上扬、感叹不平落)
- [ ] 30 秒内情绪变化不超过 2 档,强度高之后有回落
- [ ] 录音峰值 -6 ~ -3 dBFS,底噪 ≤-60 dBFS,48 kHz
- [ ] 多音字/人名/术语/数字读音表已固化并全片执行
- [ ] 同一角色音色、语速、情绪基线、口音全片一致
- [ ] 情绪强度与画面匹配,没有比画面高半档
- [ ] 逐句核对数字、年份、单位、百分比读法
