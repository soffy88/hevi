# 镜头提示词手艺手册

写生成式镜头提示词,本质是**给一个没见过你的剧本的人下摄影指令**。
它必须能让摄影师搭出景、让灯光师打上光、让摄影机架到位——同时还要躲过生成模型
最脆弱的几类画面。

## 一、标准结构(按顺序写,顺序本身有意义)

1. **主体**:谁/什么,以及他的状态
2. **动作**:正在做什么,动词开头
3. **场景**:环境、时间、天气、季节
4. **光线**:方向、质感、色温
5. **景别**:远/全/中/近/特写
6. **机位**:平视/俯拍/仰拍/过肩/主观视角
7. **运镜**:固定/推进/拉远/跟拍/左摇/环绕/手持
8. **风格**:统一的风格描述(同系列必须逐字一致)
9. **画质**:画幅、帧率、镜头焦段

示例句式:

> 中年男性,正弯腰把一只木箱推进窄巷,黄昏,侧逆光;全景,平视,缓慢跟拍;
> 手持质感,35mm,电影感低饱和;1080x1920 竖屏,25fps。

## 二、具体化:给数字,给方位,给时刻

抽象词是提示词的头号敌人。每个抽象词都要换成可执行的量:

| 别写 | 改写成 |
| --- | --- |
| 强烈的光 | 强烈侧逆光,光源在画面右后方 |
| 温暖的感觉 | 黄昏色温,高光偏暖,阴影偏冷 |
| 广角镜头 | 24mm 广角,近距离透视 |
| 电影感 | 低饱和,高对比,轻微胶片颗粒 |
| 背景虚化 | 85mm,光圈 f/1.8,背景奶油化虚化 |
| 很多人 | 七八个人,中远景,面部不可辨 |
| 一个旧房子 | 木结构土墙,窗纸破损,门框掉漆 |

四类信息一定要给:**方位**(左/右/前/后)、**时刻**(清晨/正午/黄昏/夜)、**天气**(晴/阴/雨/雾/雪)、
**数量**(具体几个)。缺这四类,同一提示词两次生成会得到两部不同的片子。

## 三、运镜与焦段

- 生成模型对**运镜词**敏感,一次只给一个运镜,两个以上会互相抵消。
- 焦段直接决定空间感:**14–24mm** 夸张透视/压迫;**35mm** 纪实;**50mm** 接近人眼;
  **85–135mm** 压缩空间/特写。景别与焦段要配对:特写 + 85mm,全景 + 24mm。
- **手持**要注明程度:"轻微手持晃动"优于"手持";"轻微"能挡住大幅抖动带来的崩坏。
- **推进/拉远**是生成最稳的运镜;**环绕**风险较高(主体形变),非必要不用。

## 四、必须回避的画面(写提示词时就绕开)

- **多人复杂交互**:三人以上互相动作、手递手的精确交接 —— 手部必崩。
- **两物精确接触**:两杯沿碰上、钥匙插孔、螺丝拧紧。
- **亚毫米级微动作**:睫毛颤、指节掐白、眼球转动、嘴角抽动。
- **清晰的文字**:招牌、书页、屏幕 UI 上写具体汉字/字母,几乎必错。
- **可辨识的真实人物**:任何在世公众人物的脸。
- **长时长连续动作**:单段超过 6 秒,后半段形变概率急剧上升。

**替换手法**:需要精确交互时,拆成"伸手"与"接过"两个独立镜头;
需要文字时,后期加字,不在生成里要。

## 五、负面提示词

按镜头可能出现的问题定制,常用基底:

> 多余手指、手部畸形、肢体扭曲、脸部扭曲、五官错位、面部模糊、
> 水印、字幕、logo、文字、拼写错误、低分辨率、噪点、过曝、塑料感、重复人物。

注意:

- 负面提示词**不宜过长**,堆太多会稀释语义,反而出怪东西。
- 遇到具体问题时**追加**针对性负面词(如"额外手臂"),不要每次重写整个负面列表。

## 六、同系列一致性(批量生成的生命线)

- **风格段逐字复制**。十镜十条提示词,风格描述必须一字不差,包括标点。
- 固定同一参考图或随机种子;同一角色的描述词表全片统一(年龄、发型、服装、气质)。
- 先用**一个代表场景**跑 4–8 个候选,把选中的风格写成"母版片段",其余镜头全部照抄。
- 角色跨镜出现时,服装、发型、体态三项必须逐字重复描述,不要用"同一个人"这种指代。

## 七、参数建议

- 单段时长 **4–6 秒**;需要更长就拆成两镜用切点接,不要一次要 10 秒。
- 分辨率与目标一致(竖屏 1080×1920 / 横屏 1920×1080),帧率与全片一致。
- 一次生成 **4 个候选**再择优,不要一条不过就改提示词重发。
- 帧率变化会造成运动质感差异(24fps 有电影拖影,30fps 更锐利),全片统一。

## 八、中英文选择

- 多数主流模型对**英文**的摄影术语(景别、镜头、胶片、光线)理解更准,复杂镜头建议英文。
- 中文优势在于**专有名词与本土场景细节**准确,本土题材可中英混写。
- 不要在同一批次里混用两种语言描述同一元素,会产生不一致。
- 无论哪种语言,**结构与具体化原则完全相同**,见第一节。

## 九、迭代方法

1. **拆解**:把出问题的画面拆成"是主体错/动作错/场景错/光线错/镜头错"。
2. **一次只改一项**。同时改五项,出了新问题也不知道是谁的锅。
3. **失败样本归档**:把失败的提示词与失败原因记下来,下次直接绕开。

## 十、常见失败模式

- **抽象词堆砌**:"唯美、治愈、高级、史诗感",生成出来一团糊。
- **信息过载**:一条提示词写八个主体、五个动作,模型会放弃其中大部分。
- **风格词每镜微调**:十个镜头像十部片子。
- **运镜词打架**:"跟拍同时快速推进",结果混乱。
- **要求写文字**:生成的中文字符必错。
- **时长贪多**:8 秒一条,后半段人物形变。
- **手部密集动作**:牵手、递物、握拳特写,崩坏率极高。
- **不给方位**:没有左右前后,同一提示词两次生成空间关系不同。

## 检查清单

- [ ] 按"主体→动作→场景→光线→景别→机位→运镜→风格→画质"顺序写全
- [ ] 抽象词已全部替换为具体量(方位、时刻、天气、数量、焦段)
- [ ] 只给一个运镜,景别与焦段配对正确
- [ ] 无多人复杂交互、无两物精确接触、无清晰文字、无真实人物
- [ ] 负面提示词针对当前问题定制,未过度堆砌
- [ ] 风格段与同系列其它镜头逐字一致,参考图/种子已固定
- [ ] 角色描述(年龄/发型/服装/体态)逐字重复,未用指代
- [ ] 单段时长 4–6 秒,分辨率帧率与全片一致
- [ ] 每镜 ≥4 个候选已择优,失败样本已归档
