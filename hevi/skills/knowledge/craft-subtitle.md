# 字幕手艺手册

字幕是观众**唯一百分之百会读**的文案。口播听不清就跳过,字幕看不清就直接划走。
字幕的错误不是"不好看",是**信息事故**——错字、错时、越界,都是 P0。

## 一、版式硬指标

- **位置**:横屏放在画面底部安全区上方;竖屏放在底部 UI 区**之上**,底边距底 ≥18%(1080×1920 下约 350 px)。
- **字号**:1080p 下 **48–60 px**;竖屏因观看距离近可略小,32–44 px。
- **描边/阴影**:**2 px** 描边或柔和投影,保证任何底图上都可读;不要用发光。
- **安全边**:左右距边 ≥5%,文字不要贴边。
- **行数**:**最多 2 行**。永远不要 3 行,竖屏尤其不行。
- **单行字数**:**≤20 个汉字**(英文 ≤42 字符)。超了就断行或改断句。
- **对齐**:居中;两行时上行略短更易读。

## 二、时间轴

- **最短显示时长 1.0 秒**。低于 1 秒,眼睛来不及聚焦,等于没写。
- **最长显示时长 7.0 秒**。超过 7 秒钉在画面上,视觉噪音极大。
- **阅读速度**:**≥8 字/秒**是底线,**4–6 字/秒**是可读舒适区。
  一条 20 字的字幕,显示 **3–5 秒**最舒服。
- **间隔(两条字幕之间)**:**至少 2 帧**(约 80 ms),否则会看成一条闪烁的长条。
- **入出点**:入点尽量与语音起点对齐,误差 ≤200 ms;出点比语音结束延后 **0.2–0.4 秒**,让观众读完。
- 字幕**不要与画面中的已有文字重叠**(招牌、台标、界面文字)。

## 三、断句(比字体重要)

- **按语义断,不按标点机械断**。"因为/所以""如果/那么"不要拆开。
- **不要把主谓宾拆开**,不要在"的""了"后面断行。
- **避免孤字行**:上行至少 4 个字。
- **禁止悬挂标点**:行首不出现 `,。!?、"` 等,标点不落行首。
- 数字、英文、专有名词尽量**整体不拆**。
- 一条字幕对应**一个完整的意群**;意群太长,宁可拆成两条并延长间隔,也不要压成三行。

## 四、标点与字符

- **全用全角标点**:`,。!?、""` 不用半角。
- 中文与数字/英文之间**不加空格**(除非原素材已有统一规范,那就全片统一)。
- 不用空格填充对齐,靠断句。
- 专有名词全片统一:同一机构/产品/人名,写法一次定死,写进词表。

## 五、说话人标注

多人对话场景:

- 格式 `名字:台词`,用全角冒号。
- 名字只写**姓或全名其一**,全片统一,不混用。
- 说话人变化时标注;同一人连续多句只在首句标,避免重复干扰。

## 六、逐字字幕 vs 意译字幕

- **逐字字幕**:口播说什么写什么,适合纪实、访谈、知识片。忠实,但啰嗦。
- **意译/提炼字幕**:改写成短句,适合口播冗长、需要提重点的内容。可读性强,但**不得改变原意**。
- 一次只选一种。混用会让观众怀疑"字幕是不是不可靠"。

## 七、特效字幕

- 关键词高亮:每屏最多 **1 处**,颜色对比明显但不刺眼。
- 引用卡/数据卡:停留 **1.5–3 秒**,位置避开底部 UI 与人物脸。
- **不使用**:逐字跳动的特效字幕(阅读负担极重)、花字、发光描边。
- 字幕动效只在**入场**做(淡入 2–3 帧),不做循环动效。

## 八、常见失败模式

- **字号太小**:手机上完全看不清,等于没有字幕。
- **贴在竖屏底部 UI 里**:被标题和按钮压住。
- **三行字幕**:竖屏三行直接顶满,极难看。
- **悬空时长远超 7 秒**:钉在画面上像 PPT。
- **断句按标点**:一屏全是逗号,读起来碎。
- **同一份文件里两种标点风格**(半角全角混用)。
- **数字/专名不统一**:前后写法不一,观众当成两个东西。
- **与语音不同步**:整体偏移半秒以上。

## 检查清单

- [ ] 字号符合平台规范(1080p 横屏 48–60 px),有 2 px 描边
- [ ] 字幕在安全区内,竖屏底边距底 ≥18%,不与 UI/画面文字重叠
- [ ] 最多 2 行,单行 ≤20 汉字,无 3 字以下孤字行
- [ ] 每条显示 1.0–7.0 秒,间隔 ≥2 帧,阅读速度 ≥8 字/秒
- [ ] 入点与语音误差 ≤200 ms,出点延后 0.2–0.4 秒
- [ ] 按语义断句,标点不落行首,全部全角
- [ ] 数字/英文/专有名词全片统一,词表已固化
- [ ] 说话人标注格式统一,同一人连续多句只标首句
- [ ] 特效字幕每屏 ≤1 处,无循环动效
- [ ] 逐字全文核对过一遍,零错字
