# 审片阶段手艺手册

审片的目的是**发现问题并分级**,不是表达喜好。"我不喜欢这个颜色"不是缺陷;
"字幕第 12 条错了一个字"是缺陷。审片结论必须能直接转成待办。

## 一、三层审片,分开做,不要混着看

| 层 | 看什么 | 谁看 | 通过标准 |
| --- | --- | --- | --- |
| 技术 QC | 能不能播、参数对不对 | QC / 工程 | 全部硬指标达标 |
| 内容 QC | 事实、字幕、连续性、一致性 | 编辑 / 编审 | 零错误 |
| 创意 QC | 好不好看、抓不抓得住 | 导演 / 出品 | 打分达标 |

一次混着看,技术问题会被"我觉得挺好"盖过去。**先过技术 QC,没过不看内容。**

## 二、技术 QC 硬指标

- **分辨率 / 帧率 / 编码**:与提案一致;帧率全片唯一,不得混。
- **时长**:与提案时长误差 ≤1%;若因内容调整超出,须走变更记录。
- **音视频流**:音轨存在、时长与视频一致、无首帧错位。
- **响度**:网络平台整片目标约 **-14 LUFS**(容差 ±1 LU),**真峰值 ≤ -1 dBTP**。
  广播版本按当地标准,但真峰值上限同样要守。
- **黑帧 / 静帧**:首尾允许 0.5 秒以内;正片中**连续黑帧 >3 帧**、**画面完全静止 >2 秒**为缺陷。
- **音频异常**:无爆音、无削波、无整段静音(>1 秒的意外静音)、底噪不高于 -60 dBFS。
- **解码**:从头到尾解码一遍不报错。文件能打开 ≠ 能播完。

## 三、内容 QC 清单

- **字幕**:错别字、人名与角色表一致、标点全角、时间轴无重叠无越界、每条不越安全区。
- **专有名词**:机构名、产品名、职务、地名与资料一致,全片统一写法。
- **数字**:画面与口播中的数字一致,与资料一致。
- **连续性**:同一角色跨镜的服装、发型、伤势、持物一致;道具位置变化有交代。
- **音画同步**:口播与画面语义对齐;字幕与语音误差 ≤200 ms。
- **结构**:开头 3 秒有没有交代"这是什么";结尾有没有落点。
- **合规**:涉及人物肖像、第三方内容、敏感表述的,已过审。

## 四、创意 QC 打分(每项 0–5,总分 25)

| 维度 | 看什么 | 及格线 |
| --- | --- | --- |
| 抓取力 | 前 3 秒能不能拦住滑动的手指 | ≥3 |
| 信息密度 | 15 秒 1 个新信息点是否落实 | ≥3 |
| 节奏 | 有没有等长镜头/拖沓段 | ≥3 |
| 可看性 | 画面是不是"有内容",不是大头念稿 | ≥3 |
| 一致性 | 人物、场景、风格是否前后统一 | ≥3 |
| 声音 | 音乐是否盖住台词,响度是否一致 | ≥3 |

**任一项 <3 分,或总分 <16,判不通过,必须返修。**
低于 2 分的维度要单独出返修方案,不能笼统写"再调调"。

## 五、返修分级

- **P0 阻断**:黑帧、错字、音画不同步、削波、结尾缺失、平台不合规。**必须修,不允许带病发布。**
- **P1 必改**:抓取力不足、信息密度不足、越轴、字幕越界、单段响度偏差 >3 LU。
- **P2 可改**:单个镜头的色调偏好、可选的空镜替换。

分级要写进审片记录,每条注明**镜头号 / 时间码 / 问题 / 责任人 / 截止**。

## 六、审片方式

- **一遍看内容,一遍只看画面,一遍闭眼只听声音**。三遍分别暴露不同问题。
- 带耳机审片:外放会掩盖中频问题。
- 至少两人独立打分,分歧 ≥2 分的维度要当面讨论,不要取平均。
- 审片记录留档:版本号、时间码、结论、签字。不留记录的返修无法追责。

## 七、常见失败模式

- **只让一个人看**:视角单一,盲区无法暴露。
- **只看一遍**:第一遍被故事带走,技术问题全部漏掉。
- **没有时间码**:反馈"第 40 秒那里有点怪",改的人找不到。
- **分数取平均**:两人分歧 5 分,平均成"还行",问题被抹平。
- **带病发布**:P0 问题知情但放行,平台侧直接限流或下架。
- **版本混乱**:改完之后不知道审的是哪一版。

## 检查清单

- [ ] 技术 QC / 内容 QC / 创意 QC 分开走,技术未过不看内容
- [ ] 分辨率、帧率、时长、编码与提案一致
- [ ] 整片响度约 -14 LUFS ±1 LU,真峰值 ≤ -1 dBTP
- [ ] 无黑帧 >3 帧,无意外静止 >2 秒,无意外静音 >1 秒
- [ ] 全片解码一遍无报错
- [ ] 字幕零错字,人名专名全片统一,时间轴无重叠越界
- [ ] 角色服装/伤势/持物跨镜一致
- [ ] 创意 QC 六维打分 ≥16 且无单项 <3
- [ ] P0 问题为零,P1 已派工并有时限
- [ ] 每条反馈带镜头号/时间码/责任人
- [ ] 至少两人独立打分,分歧已讨论
- [ ] 审片记录留档并注明版本号
