# Attribution: explainer animation skills (9 repositories)

Clean-room method graft. The nine source repositories were read only
(README, skill documents, and selected source files, via read-only
tarball extraction). No code, template, image, or other asset was
copied from any of them, and no repository was installed, run, or
connected to.

## Sources (all single MIT licence, covering each repository's own code and docs)

1. wheresryan22/anatomy -- isometric structure illustration and
   interactive demonstration; method points restated: object-as-
   explanation mapping, single-model-driven readouts, geometry audit
   discipline, shader layering contract.
2. ericblue/visual-explainer-skill -- static explanatory images;
   method points restated: analyse-first structured briefs,
   400-800 word image prompt discipline, draw-level spectrum,
   diagram-source extraction. The Gemini model string found in that
   repository's code is NOT recorded anywhere in hevi; model identity
   is always must-verify.
3. znyupup/knowledge-explainer-skill -- paginated manuscript to
   rendered video; method points restated: pagination contract,
   six layout zone maps (restated in hevi's own geometry), custom
   section naming convention. No renderer is assumed or invoked.
4. CK42BB/vox-explainer-skill -- collage-style narrated short films;
   method points restated: voice-first master clock, style anchor
   discipline, resumable per-beat project files. No paid API is
   called and no price from that repository is recorded.
5. Unclecheng-li/AI-Animation-Skill -- single-page HTML demonstration
   decks; method point restated: two-stage restructure chain and
   template selection discipline. No template file was copied and no
   CDN address is recorded.
6. adithya-s-k/manim_skill -- Manim writing practices for two
   frameworks plus a composer planning layer; only the planning
   discipline is restated (engine declared first, aha moment and
   misconception named, per-scene dwell reasons). hevi's Manim
   execution layer is independent and pre-existing.
7. iart-ai/explainer-video-skills -- five explainer modules; method
   points restated: script-first pacing with a caller-given speaking
   rate, one analogy throughout, per-scene reset and overlap audit.
   No supplier, key, or price is recorded.
8. BusyBee3333/animated-explainer-skills -- flat-illustration
   explainer animation; method points restated: choreography as a
   data vocabulary, deterministic reset discipline, 0.5 second
   overlap sweep. No scaffold code was copied and no CDN fetch is
   used; the motion library must be declared vendored or
   caller-provided.
9. brandonvant/claude-skill-whiteboard-explainer -- whiteboard reveal
   animation; method points restated: one element one picture, mask
   invariants, word-timestamp time source, hand lifecycle contract.
   The reveal engine in that repository is NOT present in hevi; every
   record in `video.whiteboard_mask_contract` states
   `hyperframes_connected: false`. No hand photograph or other asset
   was taken.

## What was NOT taken

- No template HTML, scaffold file, engine script, kit code, example
  image, or hand photograph from any source repository.
- No CDN address, API key, account, or price (including the
  time-stamped Atlas Cloud figures) as a default or threshold.
- No author-reported quality claim ("channel-grade", "VideoScribe
  level", or similar) as an acceptance standard.
- No voice cloning, third-party material, or publishing automation
  practice; none of the nine repositories describes such a practice,
  and none was introduced.

## Verification status

All eleven new capabilities were verified with unit tests and fake
fixtures only. Paid execution, real rendering engines, and the
HyperFrames reveal engine remain unconnected and are separate cases
requiring a key, a budget, or an engine installation decided by Soffy.
